# Blender 三维底片

3D 用在环境和大场面上：城市飞越、祭典街道、神社名所、日出、花海。人物场景用平面分层构图，平面角色放进 3D 场景里会很突兀。

## 1. 怎么跑

```bash
BL="/e/steam/steamapps/common/Blender/blender.exe"     # Steam 版 Blender 5.2
"$BL" -b --factory-startup --python-exit-code 1 -P F:/mv/x/src/blender/city.py -- --anim F:/mv/x/work/blender/city --range 1:300
```

- 路径一律写绝对路径，相对路径会落到 `C:\`。
- 脚本自己的参数放在 `--` 后面，常用的有：`--anim DIR` 出序列，`--range a:b` 渲一段帧，`--aux DIR` 加出描边用的辅助通道。环境变量切换段落和画风，比如 `DAWN_SEG=one4 CEL=1`。
- 帧号换算：帧 = (t − 片段起点) × 30 + 1。改一段时只重渲那一段的帧。
- 显卡 6 GB：一次跑一个 Blender；两个也能共用，但各自都会变慢。长的渲染链写成 shell 脚本放后台跑（参考 `work/v29_plates.sh`）。
- 速度参考：普通场景 0.5–1.7 秒/帧。

## 2. 底片的约定

- 输出 RGBA 的 PNG 序列，天空透明，天空、星星、烟花在合成器里画。在 Blender 5.2 里，world volume 会让天空变成不透明，雾要用有限大小的雾盒。
- 每帧把摄像机导出成 JSON（`*_cam.json`）。合成器按同一个摄像机把二维的东西（歌词、烟花、花朵、光晕）投影进去，屏幕位置才能和底片对上。相关的类：`back_v22.PlateSeq`、`GrottoCam`、`ground_quad`。
- 歌词卡片、烟花这类要贴着场景的东西，按屏幕位置反推到摄像机前面去放。近处的烟花也是这样放的。

## 3. 画风

| 文件 | 内容 |
|---|---|
| `town3.py`、`fest_city.py` | 大城市：一整块合并的网格，墙面着色器里程序化生成亮窗，用 `apply_haze()` 做远景雾，不用体积雾 |
| `toon.py` | 卡通渲染：按面的朝向分档的自发光材质，正面贴 `facade_atlas.py` 画好的立面 |
| `cel.py` | 赛璐璐着色；`CEL_DOTS` 在明暗交界处加屏幕空间网点 |
| `paint.py` | 世界空间的手绘纹理：沿构件方向的木纹、杉树枝层、石头裂缝和苔藓、瓦片、叶团，随距离淡出 |
| `fronts.py` | 墙里嵌窗、窗台、深挑檐、刷漆的侧墙、常春藤，让侧面和画好的正面配套 |
| `meisho.py`、`hana.py`、`vista.py`、`mud_road.py` | 名所一镜到底、花海、黎明的山脊和云海、雨后泥路 |

后期处理：

- **描边**：`--aux DIR` 出法线和对数深度，再用 `work/toon_post.py COLOR AUX OUT` 画墨线（深度不连续处画在近的一侧，法线折角大于约 35° 处也画）。加 `TOON_SCREEN=1` 会按亮度加网点。
- **运动模糊**：底片先渲成清晰的（`MB_POST=1`），描边和网点画完以后再用 `work/vector_blur.py` 按摄像机做矢量模糊，近处的柱子会糊到后面的墙上，反过来不会。

## 4. 摄像机

- 路径要平滑：视线方向重度滤波，只有很小的侧倾，不要随节拍晃动（被说"像坏掉的无人机"）。但用户要过每拍一个轻微的下沉、小节上更重，这是另一回事。
- 每个时刻只做一个运动，峰值转速 ≲ 50°/s，追烟花不要赶。
- 起飞和降落前后都出静帧看；检查速度和转速表，不要停在半路。
- 一镜到底时，用连续运动串起不同的景：摇上烟花再摇下河面、钻到桥下、飞进雾里。

## 5. 教训

- 场景放大以后要检查 `clip_end`：3000 曾经把 7–9 公里外的山和月亮裁掉了。
- 共面的层会闪：近处至少错开 10 cm，空中远景更多。飞起来以后把 `clip_start` 调到 4 m。
- 不要露出光秃的地面：铺满森林、田块、村子、雾，或者让镜头只拍布置好的地方（参考 `land.py`）。
- 白色自发光调暖（`work/warm_whites.py`）；树冠按朝向分明暗，不要四面一样亮。
- 近处的平面卡片会穿帮：藏起来，或者让镜头保持正对。
- 场景要真的打光：半径小的点光源给出清楚的影子；需要影子的地方放看不见的投影片。
- 每个段落要有自己的场景。好的场景被反复用，会被说"复用率太高"。
