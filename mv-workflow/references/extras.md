# 周边：封面、无字插图、投稿简介、Seedance、分享

## 1. 视频封面（参考 `work/cover.py`）

封面在引擎里画，这样和片子的调色、颗粒、纸纹一样：

- **背景**：用片子里自己的世界。比如把片头立体书小镇那个镜头停在所有层都立起来、灯笼都亮了的时刻，换一台固定的摄像机。不要另找一张图。
- **人物**：三个人面朝镜头，用同一套角色图。量两眼间距，让站在同一深度的人头一样大；主角往前一步，稍大一点。整体调暖一点，朝光源一侧加暖色轮廓光、另一侧加冷色轮廓光，身后加一团光，看起来站在场景的光里，不像贴上去的。
- **标题**：用片子自己的标题设计（这次是片尾的金色太阳纹，中间红色的「神」，后面接「のまにまに」，下面一行小字写原曲作者和演唱）。只放在干净的天空上，不压在繁杂的摊位上。
- **点缀**：落叶、金色光点、角落的前景枝叶，都避开脸和标题。
- **检查**：缩到 320×180 和 200×112 看，标题和人物在刷视频时的尺寸下要能认出来。
- **输出**：1920×1080 的 png（母版）和 jpg，再裁一张 4:3 的（B 站会要）。

## 2. 无字插图和"被太阳晃到"（参考 `work/turn_smile.py`、`work/turn_sun.py`）

- 从某个镜头取构图（这次是 0:56 回头的特写），停在动作落定的那一刻，不画字。
- 要改表情时用程序改图（见 assets.md 第 5 节），让用户在几个版本里挑。这次挑的是闭嘴微笑。
- **"被太阳晃到"是看画的人被晃到**，不是在角色眼睛里画星星。做法是渲完以后在 numpy 里做一遍眩光：
  - 整体轻微柔焦，太阳附近重度柔焦；
  - 光晕只从太阳附近的亮像素来。从所有亮的地方都起光晕的话，白衣服和脸会整片洗白；
  - 一层眩光雾提亮太阳附近的暗部；
  - 太阳放出长短不一的细光芒；
  - 横向光条要短，人物眼睛和太阳一样高时，长光条会横穿眼睛；
  - 镜头光斑放在远离脸的那一侧；
  - 画面边缘一点点色差；
  - 最后把被模糊掉的颗粒补回来。

## 3. 投稿简介、标题、标签

简介按这个结构写：

```
「歌名」非官方二创 MV

原曲：作者「歌名」
演唱：……

一段话讲这支 MV 讲了什么故事、怎么和歌对应（不引用歌词原文，歌词有版权）。
画面从哪里走到哪里。

几个小彩蛋：
0:04 ……（时间点要对着成片的镜头表核对）

制作说明：人物和部分场景素材由 AI 生成后修整，三维场景用 Blender 建模渲染，镜头、歌词动画和特效由程序合成。

音源为原曲，本作仅供欣赏，不作商业用途，如有不妥请联系删除。
```

- 「制作说明」要保留：按《人工智能生成合成内容标识办法》（2025-09-01 起施行），发布含 AI 生成内容的视频要主动声明。B 站投稿页「作者声明」里有对应的 AI 选项，提醒用户勾上。
- 标题例：`【初音ミク・鏡音リン・GUMI】歌名【故事主题・二创MV】`；标签 B 站最多 10 个（角色名、歌名、P 主、VOCALOID、二创、MV、主题词）。

## 4. Seedance（用户自己生成）

- 写一份简报（镜头描述、运动、时长、风格），导出首帧图，交给用户自己去平台上跑。
- 结果当概念测试看：金鱼盆那段生成出来是卡通色块加模糊边框，不能用；鸟居隧道那段能用。
- 能用的片段是 24 fps，转 30 fps 用 `minterpolate=mi_mode=mci`，不要用 `fps=30`（每 5 帧重复一帧，推拉镜头会抖）。
- 片段里要合成东西（石头、人物、字），先跟踪画面里的位置（这次做了一张逐帧的洞口位置表 `MOUTH`），再按位置贴上去。

## 5. 分享到 GitHub

- 默认建私有仓库：片子里是原曲音频，有版权。公开与否让用户决定。
- 单个文件超过 100 MB 不能直接进 git。1080p 母版和 720p 作为 Release 附件上传（每个附件最大 2 GB）；手机版（约 30 MB）、封面、插图、skill、源码可以直接放进仓库。
- 仓库的 README 写简介、放封面、附上视频链接，说明 AI 使用和原曲版权。
